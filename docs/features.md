# Features

각 기능은 F 번호로 참조한다. 구현 시 해당 항목의 수용 기준을 완료 조건으로 삼는다.

## F0 계정과 친구 등록

**F0-1 아이디 로그인**

- 이메일 없이 **아이디 + 비밀번호** 로 가입·로그인한다. 아이디는 영문 소문자·숫자·`_`, 3~20자. 대문자로 입력해도 소문자로 저장한다.
- 가입 시 닉네임(1~12자)을 받는다. 레이스·랭킹·신호 문구에는 닉네임을, 검색에는 아이디를 쓴다.
- 수용 기준: 가입 즉시 로그인 상태로 `/` 에 진입한다. 중복 아이디는 "이미 쓰는 아이디예요" 로 거절한다.

**F0-2 친구 요청 (아이디 검색)**

- `/friends` 에서 상대 아이디를 정확히 입력해 검색하고 "친구 요청" 을 누르면 `pending` 요청이 생긴다. 상대가 수락하기 전에는 친구가 아니고 레이스·신호에도 보이지 않는다 (2026-09-19 변경: 즉시 등록은 모르는 사람이 일방적으로 내 레이스에 들어오는 문제가 있었다).
- 내 아이디를 화면 상단에 보여줘 상대가 검색할 수 있게 한다.
- "보낸 요청" 목록에 대기 중인 요청을 보여주고 취소할 수 있다.
- 본인·이미 친구·이미 요청함·없는 아이디·차단한(당한) 상대는 각각 안내 문구로 거절한다.
- 상대가 나에게 이미 요청을 보낸 상태에서 내가 같은 상대에게 요청하면 새 요청을 만들지 않고 그 요청을 수락 처리한다.
- 수용 기준: A 가 B 에게 요청해도 수락 전에는 서로의 레이스 화면에 보이지 않는다.

**F0-3 친구 요청 수락·거절**

- 받은 요청은 `/friends` 의 "받은 요청" 목록에 보이고, 각 줄에서 수락·거절한다.
- 대기 중인 요청이 있으면 앱 진입 시 다이얼로그로 한 건씩 띄워 수락·거절을 받는다. 닫으면 목록에서 계속 처리할 수 있다.
- 수락하면 그 순간부터 양방향 친구다 — A·B 모두의 레이스 화면에 서로가 보인다.
- 거절하면 요청 row 를 지운다. 상대에게 거절 사실을 알리지 않고, 상대는 다시 요청할 수 있다.
- 요청 도착·수락은 Supabase Realtime 으로 상대 채널에 전달해 새로고침 없이 반영한다 (`friend` 이벤트). 전달 실패해도 폴링이 받쳐준다.
- 수용 기준: 두 브라우저에서 A 가 요청하면 B 화면에 새로고침 없이 다이얼로그가 뜨고, B 가 수락하면 A 의 친구 목록에 B 가 나타난다.

**F0-4 친구 삭제·차단**

- 친구 목록의 각 줄에서 "삭제" 하면 friendship row 를 지운다. 양쪽 목록에서 즉시 사라지고, 나중에 다시 요청할 수 있다.
- "차단" 하면 row 를 `blocked` 로 바꾸고 누가 차단했는지(`blockedById`)를 기록한다. 차단한 상대는 검색에 나오지 않고 요청도 보낼 수 없다 (양쪽 모두).
- 차단 목록은 `/friends` 하단의 "차단한 사람" 섹션에서 보고 해제할 수 있다. 해제 권한은 차단한 사람에게만 있고, 해제하면 row 를 지워 친구가 아닌 상태로 돌린다.
- 삭제·차단은 되돌릴 수 없으므로 확인 다이얼로그를 거친다.
- 수용 기준: A 가 B 를 삭제하면 양쪽 레이스 화면에서 서로가 사라진다. A 가 B 를 차단하면 B 는 A 를 검색할 수 없다.

## F1 퇴근 레이스 (메인)

**F1-1 버튼 연타 및 이동**

- "퇴근하고 싶다" 버튼을 누를 때마다 오늘의 누적 횟수 +1.
- 누적 횟수에 따라 졸라맨이 단계별로 전진한다. 단계와 임계값(2026-09-19 조정: 집까지 100 → 300 → 10000, 300 도 몇 분이면 끝나 하루 종일 누를 대상이 못 됐다). 간격은 뒤로 갈수록 벌어져 막판이 제일 길다:

| 단계 | 위치 | 누적 횟수 |
| --- | --- | --- |
| 0 | 자리 | 0 |
| 1 | 엘리베이터 | 1500 |
| 2 | 로비 | 3200 |
| 3 | 횡단보도 | 5000 |
| 4 | 지하철 | 7300 |
| 5 | 집 | 10000 |

- 각 단계는 경로 위에 손그림 랜드마크(책상·엘리베이터 문·로비 입구·횡단보도·전동차·집)로 표시한다. 졸라맨과 같은 연필 선이며, 지나온 곳은 진하게, 아직 못 간 곳은 연하게 그린다.

- 집(5단계)에 도착해도 횟수는 계속 누적된다 (칭호 판정용).
- 수용 기준: 탭 즉시(100ms 이내) 카운트와 캐릭터가 반응한다. 새로고침 후에도 오늘 횟수가 유지된다.

**F1-2 실시간 대결 구도**

- 랭킹은 `/ranking` 탭에서 본다 (2026-09-19 분리: 레이스 화면 `/` 이 탭 버튼과 친구 목록을 같이 담아 연타 중에 친구 줄이 밀려 올라갔다). `/` 는 내 진행만 보여주고 랭킹 탭으로 가는 링크를 둔다.
- `/ranking` 최상단에 내 레인을 고정하고, 그 아래 친구 레인만 스크롤한다. 친구가 몇 명이든 내 순위는 화면에 남는다.
- 친구들의 졸라맨이 같은 줄노트 경로 위에 표시된다. 예: `민경 273회 🚶 집 앞`, `수현 231회 🚇 지하철`.
- 친구가 탭하면 1초 이내에 랭킹 화면의 친구 캐릭터가 움직인다. 두 화면 모두 같은 실시간 구독을 쓴다.
- 랭킹은 횟수 내림차순이다.
- 수용 기준: 두 브라우저에서 `/ranking` 에 동시 접속해 서로의 이동이 보인다. 친구 목록을 끝까지 스크롤해도 내 레인이 상단에 남는다.

## F2 퇴근 신호 (친구 기능, 버튼 메시징)

- 텍스트 채팅 없음. 연타 횟수와 속도를 감지해 친구에게 상태 알림을 보낸다.
- 연타 판정 창: 마지막 탭에서 1.5초 이내 연속 탭을 하나의 연타로 묶는다 (초안).

| 연타 | 신호 | 알림 문구 예 |
| --- | --- | --- |
| 1회 | 일반 신호 | 수현이도 퇴근하고 싶어 합니다 |
| 5회 | 강한 신호 | 수현이 강하게 퇴근하고 싶어 합니다 |
| 10회 | 긴급 퇴근 신호 | 민지가 긴급 퇴근 신호를 보냈습니다 |
| 30회 | 구조 요청 | 민지가 구조 요청을 보냈습니다 |

- 한 연타 묶음에서는 도달한 최고 등급 하나만 발송한다 (5회 → 10회로 넘어가면 10회 알림만).
- 같은 등급 알림은 같은 상대에게 10분에 한 번으로 제한한다 (스팸 방지, 초안).
- 전달 채널: 인앱 토스트(실시간) → 네이티브 푸시(백그라운드) 순으로 구현. 웹 푸시(VAPID)는 iOS 웹뷰에서 동작하지 않아 쓰지 않는다 (`docs/decisions/0006-native-push-fcm.md`).
- 수용 기준: 10회 연타 시 상대 화면에 긴급 신호 토스트가 뜬다.

**F2-1 백그라운드 푸시 (ADR 0006)**

- 앱을 닫은 상태에서도 퇴근 신호가 알림으로 도착한다.
- 앱 실행 시 FCM 토큰을 받아 `TapToHome` JS 채널로 웹에 넘기고, 웹이 `POST /api/push/tokens` 로 저장한다.
- 이미 인앱으로 읽은 신호(`readAt` 이 채워진 신호)는 푸시하지 않는다.
- 알림 문구는 인앱 토스트와 같은 카피(`src/features/signal/messages.ts`)를 쓴다.
- 수용 기준: 앱을 종료한 상태에서 친구가 10회 연타하면 잠금 화면에 긴급 신호 알림이 뜬다.

## F3 하루 결과 (퇴근 도감 및 칭호)

**F3-1 행동 패턴 분석 칭호**

하루 동안의 탭 시각과 빈도를 분석해 일일 칭호를 부여한다. 횟수 기준은 F1-1 임계값과 같은 스케일로 유지한다(2026-09-19 집 10000번에 맞춰 조정). 초기 칭호 규칙(확장 가능, 목표 50개):

| 칭호 | 조건 |
| --- | --- |
| 출근하자마자 집 가고 싶었던 자 | 첫 탭이 09:30 이전 |
| 점심 먹고 모든 의욕을 잃은 자 | 13시 이후 탭이 전체의 60% 이상 |
| 퇴근 1시간 전 폭주형 | 17시 이후 탭 3000회 이상 |
| 마음만 이미 집에 있음 | 하루 10000회 이상 (= 레이스 집 도착) |
| 오늘은 버틸 만했던 자 | 하루 1000회 미만 |

- 조건이 여러 개 맞으면 모두 부여한다. 대표 칭호 하나는 우선순위 규칙으로 정한다.
- 판정 시각: 하루 종료(KST 자정) 배치, 또는 사용자가 "오늘 정산" 을 누를 때.

**F3-2 도감 수집**

- 획득한 칭호가 도감에 누적된다. 예: `14/50`.
- 미획득 칭호는 실루엣과 힌트만 보여준다.
- 수용 기준: 정산 후 도감 카운트가 올라가고, 새 칭호에 "NEW" 표시가 붙는다.

## 정산 화면

하루 종료 시 제공한다. 예: `오늘 당신은 마음만 먼저 퇴근한 자 / 총 103회 / 첫 퇴근 욕구 09:32 / 오늘 랭킹 2위`.
