# Features

각 기능은 F 번호로 참조한다. 구현 시 해당 항목의 수용 기준을 완료 조건으로 삼는다.

## F0 계정과 친구 등록

**F0-1 아이디 로그인**

- 이메일 없이 **아이디 + 비밀번호** 로 가입·로그인한다. 아이디는 영문 소문자·숫자·`_`, 3~20자. 대문자로 입력해도 소문자로 저장한다.
- 가입 시 닉네임(1~12자)을 받는다. 레이스·랭킹·신호 문구에는 닉네임을, 검색에는 아이디를 쓴다.
- 수용 기준: 가입 즉시 로그인 상태로 `/` 에 진입한다. 중복 아이디는 "이미 쓰는 아이디예요" 로 거절한다.

**F0-2 친구 등록 (아이디 검색)**

- `/friends` 에서 상대 아이디를 정확히 입력해 검색하고 "친구 등록" 을 누르면 즉시 양방향 친구가 된다 (수락 절차 없음).
- 내 아이디를 화면 상단에 보여줘 상대가 검색할 수 있게 한다.
- 본인·이미 친구·없는 아이디는 각각 안내 문구로 거절한다.
- 수용 기준: A 가 B 를 등록하면 A·B 모두의 레이스 화면에 서로가 보인다.

## F1 퇴근 레이스 (메인)

**F1-1 버튼 연타 및 이동**

- "퇴근하고 싶다" 버튼을 누를 때마다 오늘의 누적 횟수 +1.
- 누적 횟수에 따라 졸라맨이 단계별로 전진한다. 단계와 임계값(초안, 조정 가능):

| 단계 | 위치 | 누적 횟수 |
| --- | --- | --- |
| 0 | 자리 | 0 |
| 1 | 엘리베이터 | 10 |
| 2 | 로비 | 25 |
| 3 | 횡단보도 | 45 |
| 4 | 지하철 | 70 |
| 5 | 집 | 100 |

- 집(5단계)에 도착해도 횟수는 계속 누적된다 (칭호 판정용).
- 수용 기준: 탭 즉시(100ms 이내) 카운트와 캐릭터가 반응한다. 새로고침 후에도 오늘 횟수가 유지된다.

**F1-2 실시간 대결 구도**

- 친구들의 졸라맨이 같은 줄노트 경로 위에 표시된다. 예: `민경 73회 🚶 집 앞`, `수현 51회 🚇 지하철`.
- 친구가 탭하면 1초 이내에 내 화면의 친구 캐릭터가 움직인다.
- 횟수 내림차순 랭킹이 항상 보인다.
- 수용 기준: 두 브라우저에서 동시에 접속해 서로의 이동이 보인다.

## F2 퇴근 신호 (친구 기능, 버튼 메시징)

- 텍스트 채팅 없음. 연타 횟수와 속도를 감지해 친구에게 상태 알림을 보낸다.
- 연타 판정 창: 마지막 탭에서 1.5초 이내 연속 탭을 하나의 연타로 묶는다 (초안).

| 연타 | 신호 | 알림 문구 예 |
| --- | --- | --- |
| 1회 | 일반 신호 | 수현이도 퇴근하고 싶어 합니다 |
| 5회 | 강한 신호 | 수현이 강하게 퇴근하고 싶어 합니다 |
| 10회 | 긴급 퇴근 신호 | 민지가 긴급 퇴근 신호를 보냈습니다 |
| 30회 | 구조 요청 | 민지가 구조 요청을 보냈습니다 |

- 한 연타 묶음에서는 도달한 최고 등급 하나만 발송한다 (5회 → 10회로 넘어가면 10회 알림만).
- 같은 등급 알림은 같은 상대에게 10분에 한 번으로 제한한다 (스팸 방지, 초안).
- 전달 채널: 인앱 토스트(실시간) → 웹 푸시(백그라운드) 순으로 구현.
- 수용 기준: 10회 연타 시 상대 화면에 긴급 신호 토스트가 뜬다.

## F3 하루 결과 (퇴근 도감 및 칭호)

**F3-1 행동 패턴 분석 칭호**

하루 동안의 탭 시각과 빈도를 분석해 일일 칭호를 부여한다. 초기 칭호 규칙(확장 가능, 목표 50개):

| 칭호 | 조건 |
| --- | --- |
| 출근하자마자 집 가고 싶었던 자 | 첫 탭이 09:30 이전 |
| 점심 먹고 모든 의욕을 잃은 자 | 13시 이후 탭이 전체의 60% 이상 |
| 퇴근 1시간 전 폭주형 | 17시 이후 탭 30회 이상 |
| 마음만 이미 집에 있음 | 하루 100회 이상 |
| 오늘은 버틸 만했던 자 | 하루 10회 미만 |

- 조건이 여러 개 맞으면 모두 부여한다. 대표 칭호 하나는 우선순위 규칙으로 정한다.
- 판정 시각: 하루 종료(KST 자정) 배치, 또는 사용자가 "오늘 정산" 을 누를 때.

**F3-2 도감 수집**

- 획득한 칭호가 도감에 누적된다. 예: `14/50`.
- 미획득 칭호는 실루엣과 힌트만 보여준다.
- 수용 기준: 정산 후 도감 카운트가 올라가고, 새 칭호에 "NEW" 표시가 붙는다.

## 정산 화면

하루 종료 시 제공한다. 예: `오늘 당신은 마음만 먼저 퇴근한 자 / 총 103회 / 첫 퇴근 욕구 09:32 / 오늘 랭킹 2위`.
