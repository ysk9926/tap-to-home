# ADR 0011 — 홍보 릴스 애니메이션을 HyperFrames 타임라인으로 관리한다

날짜: 2026-09-20 · 상태: 채택

## 결정

홍보 릴스의 인트로(8초)·엔딩(3초)은 기존 Canvas 손그림을 유지하고, 각각 하나의 정지된 GSAP 3.14.2 타임라인을 HyperFrames에 등록한다. 앱의 런타임 의존성에는 추가하지 않는다.

- 소스는 `docs/marketing/animation/`. `build.py`가 자체 포함 HTML 미리보기와 `output/hyperframes/`의 렌더용 문서를 만든다.
- 재생 UI와 렌더용 코드를 분리한다. 모든 그림은 타임라인 시간과 고정 좌표로 결정하며, 앞뒤로 이동해도 같은 프레임을 그린다.
- 자막의 짧은 등장, 형광펜 그리기, 버튼의 눌림·복원에 `hyperframes-animation`의 `waterfall-entry`, `css-marker-patterns`, `press-release-spring` 규칙을 적용한다.
- 출근·달리기·버튼 장면은 각각 0–2초, 2–4.5초, 4.5–8초. 달리기 뒤에 책상이나 앉은 캐릭터를 남기지 않는다.
- 누운 캐릭터는 머리 원의 오른쪽 가장자리에서 몸통을 연결하고 팔을 몸통 쪽에 배치한다. 눈은 머리 중심에서 −90도 회전하고, 수면 표시는 지붕과 떨어뜨린다.
- 효과음은 `sound-cues.json`의 30fps 프레임 번호를 기준으로 합성한다. 입력 로그 시간 대신 최종 화면에서 카운터·알림·완료 상태가 바뀌는 프레임에 맞춘다. 정지된 랭킹 화면의 연타음은 제외한다.

## 이유

기존 영상은 책상 장면과 달리는 캐릭터가 겹치고, 누운 포즈의 몸통·팔이 머리를 통과했다. 그림의 연결점을 고치고, 장면 경계를 명시하며, 임의 시점 재생과 프레임별 검증이 가능한 제작 소스를 보관한다.

## 검증

HyperFrames check·snapshot·animation-map으로 타임라인을 검사하고, Canvas 내부 선과 글자의 겹침은 실제 프레임을 눈으로 확인한다. Canvas 내부 도형은 DOM 경계 검사로 판정할 수 없다. 최종 MP4의 해상도·길이·프레임 수와 HTML에 내장된 영상의 일치 여부도 확인한다. AAC 인코딩 후 효과음의 시간차·피크와 랭킹 무음 구간을 디코딩한 파형으로 검증한다.
