# Design — 줄노트 + 연필 낙서

## 방향

- 전체 배경은 줄노트. 가로줄과 왼쪽 빨간 여백선.
- 졸라맨 캐릭터와 UI 요소는 꼬불꼬불한 연필로 꾹꾹 눌러 낙서한 듯한 핸드드로잉 스타일.
- 버튼은 낙서한 사각형, 눌렀을 때 살짝 찌그러진다.
- 애니메이션은 프레임이 적은 스톱모션 느낌 (부드러운 tween 대신 2~3 프레임 교체).

## 토큰 (globals.css)

| 토큰 | 값 (초안) | 용도 |
| --- | --- | --- |
| background | #fffdf5 | 종이 |
| foreground | #2b2b2b | 기본 텍스트 |
| line | #c9d6ea | 줄노트 가로줄 |
| margin | #f4a3a3 | 왼쪽 여백선 |
| pencil | #3a3a3a | 낙서 선 |

## 에셋

- Midjourney 로 생성: 줄노트 배경 텍스처, 졸라맨 6단계(자리/엘리베이터/로비/횡단보도/지하철/집) 포즈, 버튼 프레임.
- 저장 위치: `app/web/public/assets/` (SVG 우선, 안 되면 투명 PNG 2x).
- 폰트: 손글씨 계열 한글 웹폰트 후보 검토 (미정).
