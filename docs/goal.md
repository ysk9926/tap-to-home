# Goal — Tap to Home (가칭)

## 한 줄 정의

버튼을 누를수록 내 졸라맨 캐릭터가 회사에서 집으로 먼저 퇴근하는 **정신적 탈출 레이스**에, 플레이 패턴에 따른 **칭호 수집**을 결합한 소셜 인터랙션 서비스.

## 타겟

하루 종일 퇴근만 기다리는 모든 직장인. 회사에서 몰래 켜서 몇 초 안에 누르고 닫을 수 있어야 한다.

## 왜 만드는가

- 퇴근 욕구는 누구나 갖지만 말로 꺼내기 애매하다. 텍스트 채팅 없이 버튼 하나로 "나도 집 가고 싶다"를 친구에게 전하는 통로를 만든다.
- 하루가 끝나면 그날의 패턴이 칭호로 남는다. 도감을 채우고 싶어 다음 날도 켜게 만든다.

## 대회 목표

- 원티드 AI 챔피언십 2026 출품.
- 심사 기간 동안 누구나 바로 써볼 수 있도록 **한시적 개방형 로그인** (아이디+비밀번호, 승인 없음) 적용.
- Vercel 에 배포된 웹 URL 하나로 데모가 끝나야 한다. 모바일 앱은 같은 웹을 웹뷰로 감싼 것.

## 성공 기준 (데모 기준)

1. 신규 사용자가 가입 후 30초 안에 첫 탭을 누르고 졸라맨이 움직이는 것을 본다.
2. 친구 두 명이 같은 화면에서 서로의 졸라맨이 실시간(1초 이내)으로 움직이는 것을 본다.
3. 10회 연타 시 상대에게 "긴급 퇴근 신호" 알림이 도착한다.
4. 하루가 끝나면(또는 데모용 강제 정산) 칭호가 부여되고 도감에 쌓인다.
5. 전체 UI 가 줄노트 + 연필 낙서 테마로 일관된다.

## 범위 밖 (이번 출품에서 하지 않음)

- 텍스트 채팅, 댓글
- 회사·조직 단위 그룹과 조직별 관리자 기능
- 결제, 광고
- 네이티브 전용 기능 (웹뷰 셸 이상의 모바일 구현). 단 푸시 알림은 예외로 FCM 네이티브 푸시를 쓴다 — 웹 푸시가 iOS 웹뷰에서 동작하지 않기 때문 (`docs/decisions/0006-native-push-fcm.md`).

## 확정된 질문 (2026-09-19)

- 친구 추가 방식: **아이디 검색 후 즉시 등록** (`features.md` F0-2)
- 하루의 기준 시각: **KST 자정 고정** (`src/lib/kst.ts`)
- 실시간 전송 경로: `decisions/0002-realtime.md` A 안. 채널은 사용자당 하나 `u:{userId}`
- 로그인 식별자: 이메일이 아니라 **아이디** (`decisions/0005`)

## 운영 기능 확장 (2026-09-20)

- 서비스 운영자를 위한 전체 사용자 관리와 접속·재방문·플레이 분석 대시보드를 추가한다.
- 기존 출품의 사용자 기능과 구분한 운영용 `/admin`이며, 회사·조직별 관리 기능은 포함하지 않는다.
- 관리자 영역은 별도 페이지·`/admin/login`·전용 마스터 계정으로 구성한다. 일반 회원과 인증 저장소·세션을 분리한다(ADR 0010).
- 화면·지표 정의·권한·구현 단계는 [관리자 대시보드 설계](superpowers/specs/2026-09-20-admin-dashboard-design.md), 요구사항은 `features.md` F5를 따른다.
