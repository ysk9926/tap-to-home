# Goal — Tap to Home (가칭)

## 한 줄 정의

버튼을 누를수록 내 졸라맨 캐릭터가 회사에서 집으로 먼저 퇴근하는 **정신적 탈출 레이스**에, 플레이 패턴에 따른 **칭호 수집**을 결합한 소셜 인터랙션 서비스.

## 타겟

하루 종일 퇴근만 기다리는 모든 직장인. 회사에서 몰래 켜서 몇 초 안에 누르고 닫을 수 있어야 한다.

## 왜 만드는가

- 퇴근 욕구는 누구나 갖지만 말로 꺼내기 애매하다. 텍스트 채팅 없이 버튼 하나로 "나도 집 가고 싶다"를 친구에게 전하는 통로를 만든다.
- 하루가 끝나면 그날의 패턴이 칭호로 남는다. 도감을 채우고 싶어 다음 날도 켜게 만든다.

## 대회 목표

- 원티드 AI 챔피언십 2026 출품.
- 심사 기간 동안 누구나 바로 써볼 수 있도록 **한시적 개방형 로그인** (이메일+비밀번호, 승인 없음) 적용.
- Vercel 에 배포된 웹 URL 하나로 데모가 끝나야 한다. 모바일 앱은 같은 웹을 웹뷰로 감싼 것.

## 성공 기준 (데모 기준)

1. 신규 사용자가 가입 후 30초 안에 첫 탭을 누르고 졸라맨이 움직이는 것을 본다.
2. 친구 두 명이 같은 화면에서 서로의 졸라맨이 실시간(1초 이내)으로 움직이는 것을 본다.
3. 10회 연타 시 상대에게 "긴급 퇴근 신호" 알림이 도착한다.
4. 하루가 끝나면(또는 데모용 강제 정산) 칭호가 부여되고 도감에 쌓인다.
5. 전체 UI 가 줄노트 + 연필 낙서 테마로 일관된다.

## 범위 밖 (이번 출품에서 하지 않음)

- 텍스트 채팅, 댓글
- 회사·조직 단위 그룹, 관리자 기능
- 결제, 광고
- 네이티브 전용 기능 (웹뷰 셸 이상의 모바일 구현). 푸시 알림은 웹 푸시 우선, 네이티브 푸시는 시간이 남으면.

## 열린 질문

- 친구 추가 방식: 초대 링크 vs 코드 vs 이메일 검색 → 데모 편의상 초대 링크 우선 (미확정)
- 하루의 기준 시각: 사용자 로컬 자정 vs 고정 KST 자정 → 대회용은 KST 고정 (미확정)
