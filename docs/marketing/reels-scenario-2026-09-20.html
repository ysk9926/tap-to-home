03전체 앱 흐름은 이렇게 반영했다

  1. 가입·로그인아이디·비밀번호·닉네임으로 가입. 클립 준비 단계.
  2. 친구 연결아이디 검색 → 요청 → 상대 수락. 클립 준비 단계.
  3. 내 레이스버튼 → 숫자 +1 → 졸라맨 이동. 장면 04.
  4. 친구 랭킹별도 랭킹 탭에서 서로의 진행. 장면 05.
  5. 퇴근 신호10회 연타 종료 → 친구 토스트. 장면 06.
  6. 집 도착누적 10,000회 → 침대 → 입력 종료. 장면 07.
  7. 자동 정산전날 기록 → 칭호 → 도감. 장면 08.
  8. 다음 날오늘 레이스는 0회. 수집한 칭호는 누적.

정산은 문서상 매일 KST 00:05에 전날 1회 이상 탭한 사용자 대상.“다음 날” 전환 후 정산된 기록을 보여준다. 촬영 시점의 실제 정산 상태는 별도 확인.

04제작 파일과 필요한 앱 구동 클립

소재상태용도
8초 HTML 인트로제작됨앱의 SVG 경로·내장 Gaegu 글꼴·캔버스 애니메이션. 위치 이동·재생·무음 영상 저장 기능.
실제 레이스 탭·단계 이동녹화 필요인트로 버튼의 마지막 프레임에 크기와 중심을 맞춰 이어 붙인다.
실제 랭킹 변화·긴급 신호 수신녹화 필요두 데모 세션에서 상대의 입력과 결과를 각각 확보.
실제 10,000회 집 도착녹화 필요누운 포즈와 완료 버튼을 보여준다.
정산 기록·열린 도감녹화 필요전날 10,000회 기록이 정산된 계정을 사용.
3초 HTML 엔드 카드시나리오 확정 · 제작 예정누운 졸라맨 + 앱 이름 + CTA. 인트로와 같은 종이·선·글꼴.

실제 앱 화면 확보 순서

  1. 데모 계정 두 개를 만들고 친구 요청을 수락한다.
  2. 세로 뷰포트에서 버튼·카운트·단계 이동을 녹화한다.
  3. 한쪽 랭킹 화면을 연 채 다른 쪽에서 눌러 실제 갱신을 확보한다.
  4. 10회 연타 후 손을 멈추고 상대 토스트를 녹화한다. 실제 손 촬영은 필요하지 않다.
  5. 마지막으로 9,999→10,000회 도착을 녹화한다. 도착 후 추가 입력과 신호는 막힌다.
  6. 정산된 전날 기록과 도감은 별도 클립으로 확보한다.

합성과 마감

  1. 인트로를 1080 × 1920 무음 클립으로 저장한다. 이 단계에서는 녹화 실행·인코딩 결과를 새로 확인해야 한다.
  2. 인트로 마지막 버튼과 실제 앱 버튼의 위치를 맞춘다. 전환 직후 숫자와 졸라맨이 함께 보이도록 화면을 넓힌다.
  3. 노트 배경을 끝까지 유지하고 강조는 노랑 하나로 제한한다.
  4. 효과음을 붙이고 자막과 앱 내 텍스트가 겹치지 않는지 확인한다.
  5. 실제 앱 연결 링크를 프로필에 넣은 뒤 CTA를 확정한다.
  6. 30초 완성본에서 단계·신호·다음 날 칭호의 순서를 확인한다.

앱 구동은 실제 화면 녹화이며, 인물이나 소품을 촬영하는 과정은 없다. 기존 16:9 참고 이미지에 움직임만 붙인 것을 실제 앱 구동 영상으로 표시하지 않는다. 이 문서와 8초 인트로 등록까지가 이번 산출물이며 완성 영상의 렌더링·게시 단계는 포함하지 않는다.
