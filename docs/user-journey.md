# User Journey — 하루

| 단계 | 시점 | 사용자가 보는 것 | 시스템 동작 |
| --- | --- | --- | --- |
| 출근 (Start) | 앱 첫 접속 | 나와 친구 모두 0회, 회사 자리에 서 있음 | 오늘 날짜(KST) 기준 `daily_run` 생성 또는 조회 |
| 근무 중 (Play) | 퇴근 충동이 들 때마다 | 탭 → 카운트 상승, 졸라맨 전진, 친구 캐릭터도 움직임 | 탭 기록 저장, 위치 브로드캐스트, 연타 감지 시 신호 발송 |
| 퇴근 직전 (Check) | 17~18시 | 친구 레이스 화면의 최종 랭킹 (1위 민경 103, 2위 수현 79) | 랭킹은 오늘 횟수 내림차순 |
| 하루 종료 (Wrap-up) | KST 자정 또는 "오늘 정산" | 정산 화면: 칭호, 총 횟수, 첫 탭 시각, 랭킹 | 칭호 판정, 도감 갱신, 다음 날 초기화 |

## 화면 목록

1. `/` 메인 레이스 + 친구 레이스 합침: 큰 버튼 + 내 졸라맨 + 친구 졸라맨 경로 + 랭킹
2. `/friends` 친구 목록·초대 링크
3. `/today` 오늘 정산 결과
4. `/collection` 퇴근 도감
5. `/login` 로그인
6. `/signup` 회원가입
